# Server Hub Android — نسخة نظيفة

هذا المشروع يستخدم WebView لعرض موقع Server Hub نفسه داخل التطبيق، لذلك الأغلفة والمحتوى والحساب والمالك والتنزيلات تتزامن مباشرة مع السيرفر بدون نسخة ثانية من قاعدة البيانات.

## البناء عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودعك.
2. افتح Actions.
3. شغّل Build Server Hub APK.
4. بعد Success افتح Artifacts وحمّل server-hub-apk.

## الاتصال
- نفس الهاتف مع Termux: http://127.0.0.1:8080
- جهاز آخر على الشبكة: http://IP:8080

المشروع لا يحتوي أي قاعدة بيانات ولا يحذف قاعدة بيانات Server Hub القديمة.
