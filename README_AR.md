# Server Hub Android — النسخة الجديدة

نسخة Android/Gradle أصلية وليست WebView.
تحتوي على واجهة بداية، تسجيل الدخول، نقطة إنشاء الحساب، الاتصال بسيرفر Termux، وGitHub Actions لبناء APK.

السيرفر الافتراضي:
`http://172.18.89.22:8080`

لا يتم تضمين `data.db`.

مهم: هذه نسخة بداية قابلة للبناء. المطابقة الكاملة مع API الموجود في `app.py` (الأغلفة، المالك، المكتبة، التنزيلات والمزامنة) تحتاج مطابقة endpoints الفعلية قبل اعتبارها إصدارًا نهائيًا.
